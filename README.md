# College Placement Management System

## About the Project

The **College Placement Management System** is a minor project designed to manage the college placement process digitally.

The system will help manage student information, company details, placement drives, and student applications in an organized manner.

## Technologies Used

* Java Swing
* Python Flask
* MySQL 
* Postman

## Main Modules

* Student Management
* Company Management
* Placement Drive Management
* Application Management
* Login & Authentication
* Application Status
